Hero background image placeholder

Add the Hero image as `hero-background.jpg` in this folder:
`public/images/hero-background.jpg`.

The Hero section references it from `src/sections/HeroSection.tsx` as
`/images/hero-background.jpg`. The image fills the existing rounded hero panel
with `background-size: cover` and centered positioning. A translucent overlay
keeps text readable; the existing gradients remain visible until the image is
provided. Change the URL in that component to use a different filename.
